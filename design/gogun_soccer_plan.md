# 고군분투 축구 테마 기획서

> 레퍼런스: 한게임 플래시 **고군분투** (2007). 지붕 위를 자동으로 달리는 원버튼 러닝 액션.
> 목표: 사이트에 붙는 가벼운 2D 캔버스 게임. 원작의 조작과 구조는 그대로 두고, 디자인 테마만 축구로 바꾼다.
> 원작 그림·소리·코드는 쓰지 않는다. 조작 방식과 구조만 참고하고, 그림과 코스는 새로 만든다.

## 1. 원작 분석: 고군분투

| 항목 | 내용 | 출처 |
|---|---|---|
| 정체 | 한게임 플래시 러닝 액션. 고양이 "고군"이 일본풍 지붕 위를 자동으로 달려 목적지(G)까지 감 | 나무위키 / 욘플래시 |
| 조작 | **마우스 왼쪽 버튼 하나**. 땅에서 누르면 점프, 공중에서 한 번 더 누르면 와이어를 던짐 | 나무위키 |
| 와이어 | **탑에만** 걸림. 건 뒤 포물선(진자)으로 날아감. 누르고 있는 시간과 떼는 타이밍으로 거리와 높이가 정해짐 | 나무위키 |
| 연속 와이어 | 와이어에 매달린 채 시간이 지나면 공중제비. 이때 뗐다가 다시 누르면 새 와이어를 던질 수 있음 (4~6단계에서 여러 번) | 나무위키 |
| 착지 | 자동. 지붕에 닿으면 와이어가 사라짐 | 나무위키 / 욘플래시 |
| 실패 | 지붕 사이 낭떠러지로 떨어지면 **즉시 게임 오버** (체크포인트 없음) | 나무위키 |
| 점수 | 은화 5점, 금화 약 `55 − 5×단계`점 (1단계 50 → 6단계 25). 한 단계의 금화를 다 먹으면 +200 | 나무위키 |
| 단계 | 총 6단계, 색으로 구분 (파랑 → 하늘 → 초록 → 노랑 → 주황 → 빨강). 단계마다 속도↑, 길이↑ | 나무위키 |
| 진행 표시 | 화면 아래 진행 그래프, G가 목적지. 배경 고양이 불상에 개인 최고 기록 | 나무위키 |
| 엔딩 | 크레딧 후 모은 동전으로 슬롯머신, 잭팟 연출 | 나무위키 |
| 숨은 모드 | 타이틀에서 Enter → 제작자 이름 영타 → Enter 하면 "1.5x mode"(실제 코드는 2배속). 10년 넘게 안 알려졌던 이스터에그 | 나무위키 / 욘플래시 |
| 플레이 시간 | 일반 모드 전체 클리어 약 4분 6초. 정상 플레이 완주 기록 없음, TAS만 있음 | 나무위키 |

**단계별 패턴**

| 단계 | 특징 |
|---|---|
| 1 | 낭떠러지만. 점프 한 번이면 됨 |
| 2 | 낭떠러지가 넓어지고 탑 등장. 점프 → 와이어 두 번 클릭 |
| 3 | 더 넓은 낭떠러지, 탑 2개 구간. 두 번째 클릭 타이밍이 핵심 |
| 4 | 탑 3개. 2번째에 걸거나 1·3번째에 나눠 걸기 |
| 5 | 패턴이 바뀜. 탑 4개 이상(와이어 2번 이상), 3칸 점프, 긴 낭떠러지 |
| 6 | 탑 연속 구간이 많고 더 빠름. 너무 빨리/늦게 뛰면 실패 |

- 1~4단계엔 **낚시 패턴**: 동전을 따라 뛰게 만든 뒤 낭떠러지로 떨어뜨림. 5단계부터는 낚시 대신 긴 낭떠러지와 촘촘한 탑.
- 짧은 지붕에서 "착지 되나?" 판단이 어려움. 와이어를 아끼면 떨어지고, 괜히 던졌다 착지하면 다음 점프가 늦음 → 이 **판단 압박**이 재미의 핵심.

### 재미의 핵심 (우리가 꼭 지킬 것)
1. **버튼 하나**. 누르는 순간, 누르고 있는 시간, 떼는 순간 세 가지로 모든 걸 표현
2. **진자 물리의 손맛**. 와이어를 놓는 타이밍에 따라 멀리 날아가는 쾌감
3. **고정 코스**. 랜덤이 아니라서 외우고 연습하면 늘어남 → 랭킹 경쟁이 공정함
4. **한 번 떨어지면 끝**. 긴장감. 대신 다시 하기가 아주 빨라야 함 (1초 안)

## 2. 바꾸는 것과 그대로 두는 것

**원칙: 게임 방식은 원작 그대로, 디자인 테마만 축구.** 뛰는 이유나 새 설정은 만들지 않는다.

| 원작 | 우리 게임 | 메모 |
|---|---|---|
| 고양이 고군 | **축구 선수** (호날두를 닮은 2등신: 구릿빛 피부, 앞머리를 세운 검은 머리, 빨간 7번 유니폼, 흰 반바지) | 이름은 따로 안 붙임 |
| 지붕 | 지붕 그대로. 겉모습만 **밖에서 눈높이로 본 큰 경기장 건물**의 지붕 (위가 살짝 둥근 흰 지붕 → 지붕 아래로 새어 나오는 경기장 안 조명과 관중석, 흰 V자 지지대, 대형 전광판 → 불 켜진 유리 외벽과 빨간 조명 간판 → 출입구가 있는 아래층) | 밟는 면은 판정과 정확히 같고, 건물은 지붕보다 조금 안쪽. 실제 구단 이름·로고는 넣지 않는다 |
| 탑 | 탑 그대로. 겉모습만 조명탑 (꼭대기 조명판 아래가 와이어 거는 점) | 와이어를 걸 수 있는 탑은 조명이 밝아짐 |
| 와이어 | 와이어 그대로 | |
| 은화 / 금화 | **원작처럼 은화 / 금화** | 점수도 원작 공식 |
| 배경 | 단계 색 하늘 + 멀리 경기장 실루엣 (조명탑 달린 관중석) | 단계 색은 원작 순서에서 앞 두 단계를 뺀 초록 → 노랑 → 주황 → 빨강 (원작 1·2단계는 뺐다, 4장) |
| 목적지 G | **없음 (무한 모드)**. 화면에 달린 거리(m)를 보여준다 | 5장 |

### 은화·금화 배치 (이 게임의 핵심)
- 동전은 **점프를 유도하도록** 놓는다.
- **안내 동전**: 정답 궤적 위에 놓아서, 따라 뛰면 맞는 타이밍이 된다. 앞 단계일수록 많다.
- **함정 동전**: "너무 일찍 뛰는" 궤적 위에 은화나 **금화**를 늘어놓는다. **동전 줄을 따라 뛰면 죽을 수밖에 없다.** 뒤 단계로 갈수록 많고, 금화 함정 비율도 늘어난다 (4단계 30% → 6단계 60%).
- 함정이 아닌 금화는 항상 살아서 먹을 수 있는 자리에 있다. 한 단계 금화 보너스(+200)는 **함정 금화를 빼고** 센다.
- 뒤 단계로 갈수록 은화는 줄고 금화가 늘어난다 (원작과 같음).

## 3. 조작과 물리 (프로토타입 값)

### 3.1 조작 (마우스 클릭 = 터치 = 스페이스바)
```
[지붕 위] 누름 ───────────→ 점프
[공중]   누름 ───────────→ 앞쪽 사거리 안의 가장 가까운 탑에 와이어. 헛손질은 와이어를 쓰지 않고, 누른 채로 있으면 탑이 닿는 순간 건다
         탑 꼭대기가 손보다 낮아도(4칸까지) 걸린다: 줄이 느슨하게 걸렸다가, 탑보다 내려가 팽팽해지면 흔들기 시작
[매달림] 계속 누름 ────────→ 앞으로 휘두름. 지붕에 닿아도 풀리지 않고 지나간다
[매달림] 뗌 ─────────────→ 그 순간 속도로 날아감 (지붕 속을 지나는 중이면 그 지붕 위에 내려섬)
[매달림] 끝까지 잡고 있음 ──→ 약 77도까지 올라가면 와이어가 풀리며 뒤로 공중제비. 뗐다가 다시 누르면 새 와이어
[매달림] 0.45초 넘게 매달렸다가 뗌 → 공중제비 + 와이어 한 번 더 (여러 탑 연속 이동)
[착지]   자동. 와이어를 잡고 있었으면 손을 뗐다가 다시 눌러야 점프
```
- 공중제비는 와이어에 매달려 몸이 젖혀진 각도에서 그대로 이어서 **뒤로** 한 바퀴 돈다 (앞구르기 아님)

### 3.2 속도감
- 달리기 속도는 단계로 끊지 않고 **거리에 따라 계속 빨라진다** (시작 7 → 고정 코스 끝 무렵 11.2 → 무한 구간에서 최대 14)
- 와이어는 **항상 달리기보다 빠르다**: 거는 순간 속도를 잃지 않고, 타는 동안 최소 달리기 속도의 1.3배, 놓은 직후 앞으로 최소 1.1배
- 빠르게 착지하면 0.45초에 걸쳐 달리기 속도로 돌아온다 (갑자기 뚝 끊기지 않게)
- 달리기보다 빠를 때는 속도선이 보인다

### 3.3 수치 (`public/gogun/sim.js`)
| 요소 | 값 |
|---|---|
| 물리 | 120Hz 고정 스텝 (같은 입력이면 항상 같은 결과) |
| 중력 / 점프 | 30 / 위로 11 (맨점프 거리 = 속도 × 0.73초) |
| 와이어 사거리 | 10 |
| 동전 판정 | 몸 중심에서 0.7 |
| 실패 | 지붕 옆벽에 부딪히면 미끄러져 떨어짐, 화면 아래로 떨어지면 게임 오버 |

## 4. 코스: 고정 코스 + 자동 검증

원작처럼 매번 같은 코스다. 사람이 하나하나 찍는 대신 **생성기로 한 번 만들고 데이터로 고정**했다.

- 생성기: `tools/gogun/build_course.js` (고정 시드). 실행하면 `public/gogun/course.js`를 새로 쓴다.
- 구간 종류: 맨점프 틈, 탑 1~3개, 탑 여러 개 연속(와이어 2번 이상), 3칸 연속 점프
- 탑은 **꼭 필요한 만큼만 넓게**: 간격을 점프 거리의 1.5배로 시작해서, 기준 여유로 풀리지 않을 때만 12%씩 좁혀 다시 놓는다
- **가짜 탑**은 몇 개만 (2단계 15%, 3단계 25%, 4단계·무한 30% 확률로 탑 구간에 하나). 무작위 입력 중 이 탑을 잡는 경우가 충분히 많고(40번 이상) 그중 92% 넘게 죽어야 남긴다. 정답은 가짜 탑을 안 잡는 입력으로 다시 푼다
- 도착 지붕은 좁게 (달리기 시간 0.45~1.2초, 무한 구간 끝 지붕 0.9초): 와이어를 언제 놓느냐가 중요하다
- 구간 하나를 붙일 때마다 실제 물리로 풀어서 확인한다
  - 깰 수 있는 입력이 있는지, 그 입력의 **타이밍 여유**(앞뒤로 몇 프레임까지 틀려도 되는지)가 단계 기준 이상인지
  - 함정 은화는 무작위 입력 수천 개를 돌려서, 살아남는 궤적이 그 줄의 동전을 거의 못 먹는 경우만 남긴다
- 마지막에 구간별 정답을 이어 붙인 **기준 플레이**로 고정 코스 끝까지 다시 돌린다: 끝 지붕 도착, 금화 전부, 함정 동전 0개. 이어서 게임과 똑같이 붙인 무한 구간을 4,000 거리만큼 지붕 하나씩 다시 풀어 본다

**지금 코스 (시드 33)**

초반이 지루하다는 피드백으로 원작 1·2단계(맨 점프만 있는 쉬운 단계)는 뺐다. 원래 3단계 난이도와 속도(7)로 바로 시작하고, 고정 코스는 4단계다.

| 단계 | 길이 | 타이밍 여유 (평균 / 최소) | 은화 | 금화 | 함정 은화 | 함정 금화 |
|---|---|---|---|---|---|---|
| 1 | 35초 | ±122ms / ±67ms | 68 | 17 | 0 | 0 |
| 2 | 39초 | ±113ms / ±67ms | 98 | 79 | 0 | 0 |
| 3 | 44초 | ±113ms / ±58ms | 58 | 116 | 4 | 8 (3곳) |
| 4 | 46초 | ±94ms / ±50ms | 27 | 111 | 4 | 26 (6곳) |

- 탑: 1단계 11개, 2단계 18개(가짜 1), 3단계 21개(가짜 3), 4단계 28개(가짜 3). 촘촘했을 때는 고정 구간에 149개였다
- 고정 4단계 끝까지 약 2분 21초. 그 뒤로는 무한 구간 (5장)
- 함정은 3단계부터 나온다. 함정 은화는 그 구간 틈 위에만 놓고(다음 지붕 위나 달리기만 해도 닿는 높이는 안 됨), 정답 궤적이 지나가는 자리도 피한다. 1~2단계는 지금 물리로는 "먹으면 무조건 죽는" 자리가 거의 없어서 못 만들었다 (와이어로 대부분 살 수 있음).

## 5. 모드: 무한 모드 하나

- 끝이 없다. 떨어질 때까지 계속 달린다. 연습 모드, 체크포인트 없음
- **1~4단계**는 고정 코스 (4장). 그 뒤 **5단계부터**는 미리 만들어 검증한 "구간 묶음"에서 구간을 골라 끝없이 이어 붙인다
  - 구간 묶음은 달리기 속도대별로 나뉜다: 11~11.75, 11.75~12.5, 12.5~13.25, 13.25~14, 14 고정. 속도대마다 24개
  - 구간마다 그 속도대의 가장 느린/빠른 속도 양쪽에서, 앞 지붕에 늦게 내려선 경우와 빠르게 내려선 경우 모두 깰 수 있는지 확인했다
  - 구간 고르는 순서도 고정 시드라 **누구나 같은 코스**를 달린다 (외워서 늘 수 있고 랭킹이 공정함)
  - 지붕 높이가 -1.5~1.5를 벗어나지 않게 구간을 고른다
- 속도는 거리에 따라 계속 올라가 무한 구간에서 14까지 오른 뒤 그대로
- 무한 구간 단계는 450 거리마다 하나씩 올라간다. 단계 색은 4단계 뒤 보라 → 남색 → 밤하늘을 돌아가며
- 금화 점수는 원작 공식 `55 − 5×단계`인데 무한 구간에서는 20점 아래로 내려가지 않는다

## 6. 화면

- **가로 화면 전용.** 폰을 세로로 들고 있으면 게임 전체를 90도 돌려서 보여준다 (폰을 왼쪽으로 눕혀서 하게 됨). 터치 기기에서만 돌린다 (PC 창이 세로로 길어도 그대로)
- HUD: 왼쪽 위 홈 / 점수 / 달린 거리(m), 가운데 단계, 오른쪽 위 최고 기록 / 소리
- 단계 시작 배너, 금화 전부 보너스 배너, 동전 +점수 표시
- 게임 오버: 점수, 몇 단계·몇 m에서 떨어졌는지, 최고 기록. 화면 아무 데나 누르거나 스페이스바로 바로 다시 시작
- 그림은 이미지 파일 없이 캔버스로 직접 그림. 소리는 WebAudio로 만든 짧은 효과음

| 파일 | 내용 |

## 8. 사이트 연결 (2026-11-01 배포, 메인 화면 버튼 포함)

| 파일 | 한 일 |
|---|---|
| `public/index.html` | 메인 화면에 "고군분투" 카드 (발롱도르 만들기 다음) |

| `firestore.rules` | `knownGames()`에 `gogun`, `gogunLeaderboard/allTime/entries/{deviceId}` 규칙 (닉네임·점수·도달 단계, 최고 기록일 때만 갱신, 무한 모드라 점수 상한은 여유치 10,000,000, `sessionConsumed('gogun_' + deviceId, 10)`) |

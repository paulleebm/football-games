# 이름 뒤죽박죽 기획서

> 선수 **풀네임의 모든 알파벳을 한데 뒤섞어** 내고, 타일을 눌러 원래 철자로 되돌리는 퍼즐.
> 게임에 들어가면 **바로 문제**가 나온다. 풀거나 스킵하며 끝없이 도전한다.
> 시간 제한, 힌트, 리더보드는 없다.
> 출제 풀은 **이 게임 전용 고정 목록 219명** (카드팩 레어 이상에서 유명한 사람만 골랐다). 아래 0장 참고.
> 상태: 프로토타입 (`public/scramble/`).

---

## 0. 출제 풀 (`public/scramble/players.json`, 219명)

이 게임 전용 **고정 목록**이다. 카드팩 데이터와 연결하지 않는다 — 카드팩이 바뀌어도 이 게임은 그대로다.

### 만든 방법 (2026-11-01)
1. 카드팩 기준 **레어 이상**을 모았다: 현역(CAPTCHA 선수 + `card/extra_players.json`) 중 EA FC 능력치 81 이상, 은퇴 레전드(아이콘) 전체, 레어 이상 감독. 여기에 등급은 일반이지만 한국에서 잘 알려진 14명(이강인, 래시포드, 도쿠, 셰슈코, 페드루 네투, 쿠두스, 솔랑케, 가브리엘 제주스 / 감독 데 로시, 가투소, 파브레가스, 아모림, 데 제르비, 모예스)을 더했다 → 438명.
2. 같은 사람 중복은 하나만 (손흥민: 은퇴 레전드로만).
3. **유명도 기준으로 손으로 걸렀다**: 한국 축구 팬이 이름을 들어도 잘 모를 선수를 모두 뺐다 (197명). 능력치가 높아도 덜 알려졌으면 뺐다 (예: 그리말도, 쇠를로트, 로보트카, 디 로렌초, 코벨, 슐로터베크). 감독은 너무 어려워서 **정말 유명한 10명만** 남겼다: 퍼거슨, 벵거, 클롭, 안첼로티, 과르디올라, 무리뉴, 시메오네, 아르테타, 루이스 엔리케, 사비 알론소.

| 구분 | 인원 | 정답 공개 때 표시 |
|---|---|---|
| 현역 | 171 | 소속팀 |
| 은퇴 레전드 | 38 | 은퇴 레전드 |
| 감독 | 10 | 감독 · 팀 / 전설의 감독 |

- 항목: `id`, `name`, `sub`(정답 공개 때 이름 아래 한 줄), `photo`(public 기준 경로), `cutout`(전신 누끼 사진이면 true — 동그란 사진에서 위쪽을 보여준다).
- 사진은 파일을 복사하지 않고 카드팩·CAPTCHA 이미지 경로를 그대로 쓴다. 그쪽 이미지가 지워지거나 이름이 바뀌면 여기서 깨진다.
- 소속팀(`sub`)은 만든 날 기준이다. 이적해도 자동으로 안 바뀐다.
- 기록 키(`scrambleSolvedV1`)는 그대로. 목록에서 빠진 사람을 이미 풀었던 기록은 해결 수에 안 센다.
- 사람을 더하거나 빼려면 `players.json`을 직접 고친다.

## 1. 흐름

- 허브의 카드를 누르면 바로 문제 화면. 문제 목록이나 시작 화면은 없다.
- **문제 = 한 사람** (선수·레전드·감독). 전체 문제 수 = 출제 풀 인원(219).
- **우상단**에 `해결한 수 / 전체 수` (예: `12/219`).
- 문제는 **아직 못 푼 선수 중에서 무작위**로 나온다. 한 번 푼 선수는 다시 나오지 않는다.
- 할 수 있는 것은 두 가지:
  - **풀기**: 다 맞히면 칸이 초록으로 바뀌고 선수 사진·이름·소속팀이 나온다. `다음 문제 →` (또는 Enter)로 넘어간다.
  - **스킵**: 벌점 없이 바로 다음 문제. 스킵한 선수는 못 푼 채로 남아 나중에 다시 나올 수 있다 (바로 다음 문제로는 안 나옴).
- **도전은 무한**: 판, 목숨, 문제 수 제한이 없다. 나갔다 와도 해결한 수는 그대로다.
- 모두 풀면 "모두 맞혔어요" 화면. `처음부터 다시 풀기`로 기록을 지울 수 있다 (확인 창).

## 2. 문제 형태

- **풀네임 전체**를 낸다 (Bukayo Saka, Trent Alexander-Arnold). 한 단어 이름은 그대로 (Pedri, Rodri).
- **글자는 단어 구분 없이 전부 섞는다.** `BUKAYO SAKA` → `KAUSYAKBOA` 한 줄.
  - 단어별로 섞으면 한 단어만 풀어도 누군지 알게 되고 나머지는 단순 입력이 된다.
- **칸에도 띄어쓰기·하이픈을 표시하지 않는다.** 이름 전체 글자 수만큼 칸이 이어져 있다 (`BUKAYO SAKA` → 칸 10개). 몇 단어인지, 어디서 끊기는지도 스스로 떠올려야 한다.
  - 12칸까지는 한 줄, 넘으면 두 줄로 반씩 나눈다 (단어 경계와 상관없이).
- 타일을 누르면 앞에서부터 차례로 빈칸이 채워진다. 채워진 칸을 누르면 타일로 돌아간다.
- PC는 키보드: 글자 입력, Backspace(마지막 글자 빼기), Esc(전부 비우기), 맞힌 뒤 Enter(다음 문제).
- 모든 칸이 차면 바로 판정. 틀리면 흔들리고 빨갛게 표시되며, 글자는 그대로 둬서 고칠 수 있다.
- `섞기`: 남은 타일 순서를 다시 섞는다. `비우기`: 칸을 전부 비운다. `스킵`: 다음 문제.

### 글자 정리
- 악센트는 뗀다: `é → E`, `ü → U`, `č → C`. 타일은 대문자 알파벳만.
- NFD로 안 쪼개지는 글자는 표로 바꾼다: `ø → O`, `ı → I`, `ß → SS`, `ł → L`, `đ → D`, `æ → AE`.
  (기존 허브의 `normalize()`도 `Ødegaard`, `Yıldız`를 못 처리한다. 별도 수정 대상.)
- 맞힌 뒤에는 원래 철자(`Martin Ødegaard`)를 보여준다.

### 섞기 규칙 (`logic.js`의 `scramble`)
문제가 나올 때마다 새로 섞는다. 원래 철자가 비쳐 보이면 다시 섞는다.
- 원래 철자와 같으면 안 됨
- 제자리에 남은 글자가 `⌊길이/3⌋`개 이하
- 첫 두 글자가 원래와 같으면 안 됨
- 3글자 이상 단어가 통째로 붙어 있으면 안 됨 (`...SAKA...`)

### 난이도
따로 조절하지 않는다. 순서가 무작위라 9자(Harry Kane)와 20자(Trent Alexander-Arnold)가 섞여 나온다.
어려우면 스킵하고 나중에 다시 만나는 구조라서, 난이도 곡선 대신 "고르는 자유"로 푼다.

## 3. 저장

- `localStorage`의 `scrambleSolvedV1`: 푼 선수 id 배열.
- 선수 id로 저장하므로 **선수 데이터가 갱신돼도 기록이 어긋나지 않는다.**
  - 새 선수가 추가되면 전체 수가 늘고 못 푼 문제로 나온다.
  - 빠진 선수는 해결 수에서 자동으로 빠진다.
- 풀던 중인 문제(놓아 둔 글자)는 저장하지 않는다. 새로고침하면 다른 문제가 나온다.

## 5. 남은 문제 (알고 가는 것)

- **치팅을 막지 않는다.** 정답 이름이 데이터 파일에 그대로 있다. 겨룰 순위가 없고 포인트도 선수당 한 번이라 문제 삼지 않는다.
- **포인트 내역이 선수마다 한 줄씩 쌓인다.** points.js 내역은 최근 500줄만 남기므로, 많이 풀면 다른 게임 내역이 밀려날 수 있다. 신경 쓰이면 10명마다 묶어서 적립하는 식으로 바꾼다.
- **철자 시험이다.** 한국 유저는 한글 이름으로 기억한다. 스킵이 있어서 막혀도 진행은 되지만, 긴 이름만 계속 남으면 후반이 지루할 수 있다.
- **이름 기준이 FotMob이다.** FC27 표기와 다를 수 있다 (예: Vinícius Júnior).
